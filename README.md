# 🔐 CyberSecurity Suite

## 📌 Project Overview
A 3-in-1 cybersecurity tool developed for educational purposes as part of the **PINNACLE LABS Internship Program 2026**.

---

## 🛠️ Features

### 🔑 Password Analyzer
- ✅ Real-time password strength check
- ✅ Common password detection
- ✅ Breach detection via HaveIBeenPwned API
- ✅ Improvement suggestions

### ⌨️ Keylogger (Educational)
- ✅ Silent background execution
- ✅ Auto-start via Windows Registry
- ✅ Telegram integration
- ✅ Screenshot capture on exit
- ✅ Timestamp logging

### 🔐 Text Encryption
- ✅ AES Encryption
- ✅ DES Encryption
- ✅ RSA Encryption
- ✅ User-friendly GUI
